使用 GitHub Pages 发布静态博客

2026.10.02 · 教程 · 5 分钟阅读

GitHub Pages 可以将仓库中的静态文件发布为网站。将本项目上传到 GitHub 后，即可通过 Pages 部署。

部署步骤

  1. 在 GitHub 创建一个新仓库，例如 fates-blog。
  2. 上传本项目所有文件并推送到 main 分支。
  3. 进入仓库的 Settings → Pages。
  4. 在 Build and deployment 中选择 GitHub Actions。
  5. 等待 Actions 工作流完成，然后打开 Pages 提供的网址。

更新博客

修改页面、样式或文章后，提交并推送到 main 分支，工作流会自动重新部署。

自定义

首页文章卡片目前直接写在 index.html 中。新增文章时，复制 posts/welcome.html 修改内容，再在首页添加对应卡片即可。若使用项目仓库部署，资源路径按相对路径组织，可正常适配子目录。
